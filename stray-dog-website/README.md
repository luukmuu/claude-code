# Stray Dog Website

A minimal and clean Next.js website for stray dog rescue and adoption services.

## Features

- Clean, minimal design with blue color scheme
- Left sidebar navigation
- Responsive layout
- SVG dog illustration
- Multiple sections: Home, About, Services, Gallery, Contact

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Technology Stack

- Next.js 15
- React 18
- TypeScript
- Tailwind CSS
- App Router

The website uses a blue color palette:
